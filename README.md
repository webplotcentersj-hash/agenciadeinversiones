# Invitación — Grupo Agencias · 10 años

Invitación digital para el aniversario de Grupo Agencias (inversiones, automotores y construcciones).

```bash
npm install
npm run dev
```

## Dónde tocar el contenido

Todo el contenido vive en [`lib/event.ts`](lib/event.ts):

- `BRAND` — nombre del grupo, aniversario y ciudad.
- `AGENCIES` — las tres agencias, servicios y direcciones.
- `EVENT_HAS_DATE` — poner en `true` cuando confirmen día y hora. Eso muestra el contador y la fecha en la tarjeta.
- `EVENT_ISO` / `EVENT` — fecha, hora y datos de calendario.

## Qué se muestra hoy

- Hero: **Celebramos 10 años**.
- Tarjeta de aniversario (el 10 grande).
- Las tres casas sobre Ignacio de la Roza, San Juan.
- Ficha de cada agencia con servicios y mapa.
